# Intelligent Emergency Response and Rescue Agent

## Project Overview

This project is designed to help find rescue routes during emergency situations.

It allows users to report emergencies and find routes to rescue centers using search algorithms.

## Features

- Emergency reporting
- Rescue route finding
- BFS algorithm
- DFS algorithm
- Dijkstra algorithm
- A* algorithm
- Interactive map
- Traffic and road management

## Technologies Used

- Python
- Streamlit
- NetworkX
- PyDeck
- Visual Studio Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the required libraries:

   pip install streamlit pydeck networkx

4. Run the application:

   python -m streamlit run app.py

## Conclusion

This project demonstrates how search algorithms can be used to find suitable routes during emergency situations.

It is developed as an academic project for learning purposes.
